How Cerberus Access Control Works (ELI15)

Imagine you’re at a magical library with different rooms. Your student ID (role) decides which rooms you can enter and which books you can borrow.

  • You choose your role (Student, Prefect, Teacher).
  • The system checks what you’re allowed to see and do.
  • You request a book—the system asks the “librarian” (server) if you’re allowed.
  • If yes, you get the book. If no, you get a friendly “no entry” message.
Key Idea: Your role controls what you can see and do, and the server always double-checks before letting you in!
